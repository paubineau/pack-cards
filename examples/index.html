How this example works
The example owns the six cards, navigation index, and viewed sizes. createPackCards handles presentation; createCardPile handles the pile and dealing. Snapshots carry the outgoing card’s materials into the animation.
import {createPackCards} from 'pack-cards';
import {createCardPile} from 'pack-cards/collection';
import {snapshotCard} from 'pack-cards/snapshots';
import 'pack-cards/styles.css';
For the smallest complete integration, start with the starter example. The full source shows cleanup and the pack-to-card handoff.

Use the editor independently
import {createAppearanceEditor} from 'pack-cards/editor';
import 'pack-cards/editor.css';

const editor = createAppearanceEditor(host, {
  initial: settings,
  onChange: (settings, target) => updatePreview(settings, target),
});
// Your app owns saving. Call editor.dispose() on unmount.
You can also provide your own controls using the appearance helpers. Import pack-cards/base.css on its own to supply a custom card layout; styles.css adds the default content theme used here.

Ready to make a copy.

      
What the helper owns
import {snapshotCard, createCardDragPreview} from 'pack-cards/snapshots';
import 'pack-cards/snapshots.css';

const copy = snapshotCard(face);
tray.replaceChildren(copy);
Snapshots preserve canvas pixels, scroll position, and material variables. They do not copy event listeners. The drag helper adds a sized visual preview; this example supplies pointer tracking and drop behavior. A snapshot is a DOM copy, not a PNG.
